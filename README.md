# Lugx - Gaming Shop

![React](https://img.shields.io/badge/React-18-61DAFB?logo=react&logoColor=white)
![Vite](https://img.shields.io/badge/Vite-build-646CFF?logo=vite&logoColor=white)
![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-4-38B2AC?logo=tailwindcss&logoColor=white)

A responsive gaming gear shop interface built with React, Vite and Tailwind CSS.

**Live Demo:** https://lugx-gaming-shop-tau.vercel.app

## Features

- Shop catalog with product cards and detail pages
- Hero, trending, categories and contact sections
- Fully responsive layout styled with Tailwind CSS
- Icon set powered by lucide-react

## Tech Stack

- React 18 + Vite
- Tailwind CSS 4
- lucide-react

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

Deployed on Vercel: https://lugx-gaming-shop-tau.vercel.app
